# MT5 Multi-Grid EA

MQL5 Expert Advisor for multi-position grid trading with custom trailing stop.

## Features

- 3 Grid modes (Manual, Auto Grid, Bottom Grid)
- Risk Cap (Account %)
- Server TP / TP1 management
- Hybrid Trailing Stop
- Mobile position detection

## Installation

1. Copy the EA file to your MT5 `Experts` folder
2. Restart MT5 or refresh Navigator
3. Attach EA to chart and configure parameters
